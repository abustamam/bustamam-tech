# Project Images

This directory contains images for consulting and employment projects.

## Directory Structure

- `consulting/` - Images for consulting projects
- `employment/` - Images for employment projects

## Image Guidelines

1. **File Format**: Use PNG, JPG, or WebP format
2. **Recommended Size**: 400x400px or larger (square aspect ratio works best)
3. **File Naming**: Use kebab-case based on company name (e.g., `edvo.png`, `layer-one.png`)
4. **Optimization**: Compress images before adding them to reduce file size

## Adding Images

1. Place the image file in the appropriate directory (`consulting/` or `employment/`)
2. Use the filename listed above (or update the data file if using a different name)
3. Ensure the image is optimized for web use
